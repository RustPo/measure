# Замер скорости скачивания

[![tests](https://github.com/RustPo/measure/actions/workflows/test.yml/badge.svg)](https://github.com/RustPo/measure/actions/workflows/test.yml)

Консольный скрипт на Node.js: делает несколько запросов к одному адресу **последовательно**, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём данных и скорость скачивания.

Требования: Node.js 20+ (встроенный `fetch`), зависимостей нет. Проверяется в CI на Node 20 и 22.

## Запуск

```bash
node measure.mjs <url> [количество_запросов]
```

Количество запросов по умолчанию 10. Пример:

```bash
node measure.mjs https://example.com/big-image.jpg
node measure.mjs https://example.com/big-image.jpg 5
```

Для осмысленного результата берите достаточно тяжёлый файл (от нескольких мегабайт). На маленьких файлах основную долю времени занимает задержка до сервера, а не скорость канала.

## Что выводится

```
#01:   1234 мс, 5120.0 КиБ
...
--- Итог ---
Успешных запросов:     10 из 10
Среднее время запроса: 1180 мс
Скачано всего:         52.43 МБ (52428800 байт)
Скорость скачивания:   35.55 Мбит/с (4.44 МБ/с)
```

## Единицы измерения

- Скорость: **Мбит/с** (1 Мбит = 1 000 000 бит), как в тарифах провайдеров. Дополнительно **МБ/с** (1 МБ = 1 000 000 байт).
- Время: миллисекунды (мс).
- Объём: МБ (десятичные) в итоге, КиБ (1 КиБ = 1024 байта) в строках по запросам.

## Как считается

- Время запроса: от начала запроса до получения последнего байта тела ответа.
- Скорость = всего скачанных байт / суммарное время запросов. Это не среднее арифметическое скоростей отдельных запросов, иначе короткие быстрые ответы искажали бы результат.
- Запросы последовательные: параллельные делили бы один канал и искажали время каждого.
- Запрашивается ответ без сжатия (`Accept-Encoding: identity`), чтобы считались реально переданные байты.
- Тело читается потоком и не хранится в памяти.
- Встроенный `fetch` переиспользует соединение (keep-alive), поэтому установка соединения (DNS, TCP, TLS) входит только во время первого запроса.

## Поведение при ошибках

- Таймаут: 30 секунд на весь запрос.
- Ответ не 2xx, сетевая ошибка или таймаут: запрос пропускается, в статистику не входит, число ошибок выводится в итоге.
- Код выхода: `0` все запросы успешны, `2` были ошибки, `1` неверные аргументы или не удался ни один запрос.

## Тесты

```bash
node --test
```

Используется встроенный раннер `node:test`, зависимостей нет. Скрипт запускается как отдельный процесс против локального HTTP-сервера, поэтому сеть не нужна. Проверяются: количество запросов, подсчёт объёма, ошибки сервера, коды выхода и валидация аргументов (`measure.test.mjs`).

## Ограничения

- Время не разделено на задержку до первого байта и скачивание тела, поэтому на небольших файлах результат отражает в основном задержку.
- Результат зависит от сервера, расстояния до него и нагрузки на сеть: это оценка, а не точный бенчмарк канала.
